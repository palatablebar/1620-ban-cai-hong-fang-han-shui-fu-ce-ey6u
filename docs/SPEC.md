# 数据与模型契约

先看字段单位和历史截止，再解释预测与排班。

## 现场观测

| 字段 | 含义 | 单位 | 样本常见范围 |
| --- | --- | --- | --- |
| `thickness` | 板材厚度 | mm | 10–38 |
| `hours` | 烘干时长 | 小时 | 6–39 |
| `steam` | 蒸汽阀开度 | % | 12–95 |
| `inlet` | 进料含水率 | % | 14–39 |
| `level` | 堆垛层位 | 层 | 1–8 |
| `vent` | 风阀开度 | % | 11–91 |

## 可见性与结果

`day` 为业务序列日，`received` 是录入日期。`revision` 只在可见窗内选最大版，同版内容冲突整键隔离。`arrival` 和 `window` 用当日分钟表示，分派沿半开区间，片区和 `pool` 标识不同业务位置。

历史结果字段 `target` 表示下线含水率，`outcome_day` 是结果首次可见日。`complete=0` 的不完整单据不参与普通标签回放，清线模型按右截尾留作下界。结算项目的 `target` 是参考发电量，`confirmed` 表示实测表计偏差是否被稽核确认。

## CART 回归树

按五组加工变量的分位阈值候选递归做 CART 分裂。叶子保持最小样本，深度只由训练窗尾段选择。

预测和误差带采用业务原始单位，采用校准窗绝对误差的有限样本分位。

特征中位和尺度只在训练窗估计。无已知片区、缺关键测量或超出训练支撑会转人工。归因记录单轴回到训练参考值后对原始分数的变化。

## 资源和发布

一单位资源为复测班组半小时。同窑同层视为一个工位，补测要留见证点且不能跨冷却窗口。
预算等于已用、可用剩余、预留三者之和。发布复核固定模型和源摘要，同时检查当前版本。已发布内容通过不可变标识回看。
