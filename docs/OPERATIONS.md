# 当班处置

收到新一批烘房层位单时先运行 `validate`。有隔离记录时对照 `reasons` 回查来源单号，再通过 `preview` 确认是否仍能覆盖当班。

## 先重算再发布

1. 先看 `/api/replay` 的保留样本、基线证据和各舱放行误差带。高风险与证据不足的对象会分别进入派工和人工队列；没有可信误差带的层位转人工。
2. 按本班复测班组半小时调低预算或增加预留。查看每个片区的已用数量及待分派原因，核对保护资源。
3. 确认派工窗口后发布。相同预览再次提交会返回原版，旧版请求遇到其他派工已发布时须重算。
4. 从 `/api/ledger` 查询版号，按摘要获取完整快照或下载 CSV 与现场票据复核。复测单与 CSV 都标出本条用到的误差带（本舱带名与半径）。

本班主要动作是「安排翻层复测」。同窑同层视为一个工位，补测要留见证点且不能跨冷却窗口；该复测却排不进冷却窗的层位留候补。
数据含模拟异常，缺少可见证据或排班资源时如实返回等待或转人工。
